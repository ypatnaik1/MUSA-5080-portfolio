Reading a logged predictor

From the Oct 9 lecture: tract rent on log of median income.

\[\widehat{\text{rent}} = \beta_0 + 210 \cdot \log(\text{income})\]

  • β̂ reading: a 1% increase in income goes with about 210 / 100 = $2.10 more rent.
  • ŷ reading: it lets the model bend, so it doesn’t over-predict rent in the richest tracts.

The rule

Log X, keep Y in dollars: β / 100 = change in Y for a 1% change in X.

The fold that broke

Error: factor district has new levels Upper Far Northeast

Where is the model wrong?

A model, and its errors

m1 <- lm(sale_price ~ total_livable_area + number_of_bathrooms + age +
           violent_knn5, data = sales)

sales <- sales %>%
  mutate(pred  = predict(m1, sales),
         resid = sale_price - pred)      # + means the model guessed too LOW

Sign convention, all semester

residual = actual − predicted. Red = actual higher than predicted (we under-predicted).

Today we put a number on “do the errors cluster?”

Tobler: near things are more related than distant things.

If near houses have related errors, the model is missing something about place.

The spatial lag: my neighbors’ average

coords <- st_coordinates(sales)
w_knn  <- nb2listw(knn2nb(knearneigh(coords, k = 5)), style = "W")

sales$resid_lag <- lag.listw(w_knn, sales$resid)

Each house gets the average residual of its 5 nearest neighbors.

Me vs. my neighbors

ggplot(sales, aes(resid, resid_lag)) +
  geom_point(alpha = 0.15, size = 0.6) +
  geom_smooth(method = "lm", se = FALSE, color = "#b2182b") +
  coord_cartesian(xlim = c(-3e5, 3e5), ylim = c(-2e5, 2e5)) +
  labs(x = "My residual", y = "Average of my 5 neighbors' residuals")

The slope of this line is Moran’s I (with row-standardized weights).

Moran’s I: the scary formula

\[I = \frac{n}{\sum_i \sum_j w_{ij}} \cdot \frac{\sum_i \sum_j w_{ij}(x_i - \bar{x})(x_j - \bar{x})}{\sum_i (x_i - \bar{x})^2}\]

It’s asking one question:

When I’m above average, are my neighbors above average too?

Five houses on a block

Neighbors are the houses next door.

Positive residual means we under-predicted that house.

Multiply neighbors

Pair Product
A–B (+84)(+64) = +5,376 both under-predicted
B–C (+64)(+4) = +256
C–D (+4)(−66) = −264 different signs
D–E (−66)(−86) = +5,676 both over-predicted

Each pair counts twice (A→B and B→A): sum = 2 × 11,044 = 22,088

Σ deviation² = 7,056 + 4,096 + 16 + 4,356 + 7,396 = 22,920

\[I = \frac{5}{8} \cdot \frac{22{,}088}{22{,}920} \approx \mathbf{0.60}\]

Strong clustering: the under-predictions sit together, and so do the over-predictions.

Reading Moran’s I

I Pattern For our errors
near +1 similar values cluster the model is missing something about place
near 0 no spatial pattern the errors look like noise in space
below 0 neighbors differ rare for errors; check your weights

Is that big? Shuffle and see

mc <- moran.mc(sales$resid, w_knn, nsim = 499)
mc$statistic

moran.mc shuffles the residuals across houses 499 times. If the real I beats almost all the shuffles, the clustering isn’t luck.

p-value warning, again

With 20,000 houses, nearly everything is “significant.” Watch the size of I fall as you add features. That’s the diagnostic.

Clustered errors are a feature you haven’t built yet

If Moran’s I is high, ask what’s true about those places that the model doesn’t know:

  • An amenity or disamenity you haven’t measured → spatial feature
  • Something about the whole neighborhood → neighborhood fixed effect
  • A relationship that differs by place → interaction

Then refit, recompute I, and log both numbers.

“My spatial stats class says use a spatial lag model”

\[y = \rho W y + X\beta + \varepsilon\]

That’s the right tool for inference about spillovers. For prediction it fails three ways:

  1. It needs neighbors’ prices. To price a house, you’d need the prices of houses that haven’t sold yet.
  2. It leaks. In CV, a test house’s neighbors in the training set carry its answer.
  3. It explains nothing. “Near expensive houses” is not a reason a policymaker can act on.

Our rule: spatial features of X, never Y. Crime near the house is fine; prices near the house are not.
